# Phase 1.2 Corrected Robustness Benchmark

## Separation of evidence

The evaluation now has three distinct artifacts:

- **Regression:** 24 original cases generated by the same structural patterns
  as the v1 rules. They check formal behavior and are not independent evidence.
- **Controlled robustness:** 32 authored cases specified before running any
  method. Labels use real ArtGraph IDs and recorded facts, but were authored by
  the implementation agent and still await independent human review.
- **Human relevance:** 16 unscored, method-blind, text-only comparisons. Their
  responses must never be mixed into controlled metrics.

The robustness benchmark has four cases in each category: true atomic,
multiple independent interests, true conjunction, noisy observations,
contradictory evidence, missing evidence, ambiguous histories, and explicit
corrections. Four ambiguous scenarios contain two controlled worlds behind
the same input, producing 36 worlds. Worlds are averaged within their scenario
and never counted as independent samples.

## Construction and audit

`scripts/build_preference_state_robustness.py` contains fixed case cards. It
does not import or execute an inference method. It validates IDs against the
112-artwork snapshot, attaches existing `agf_*` provenance, computes relevance
from the authored profiles, and deterministically randomizes candidates with
seed `32631202`.

The 24 regression targets occupy positions 1–5 with counts 2, 6, 7, 2, and 7.
No development/held-out group ID or complete observation history overlaps.
Three observation artworks overlap, and the common candidate pool necessarily
overlaps. Development conjunctions use genre+style; held-out conjunctions use
style+tag. One atomic water profile overlaps. These facts support an
**in-pattern** label only.

Missing-evidence cases hide selected real fact IDs in a test-only view and
declare that view incomplete. Source facts remain intact. Corrected inference
then disables interaction inference and reports insufficient evidence. This
tests known missingness; silent unknown missingness is unresolved.

## Results and failures

Compositional Prolog and the independent interaction Python comparator match
on every decision, explanation, and ranking. Across all 32 scenarios they
obtain 96.88% coverage, 59.38% primary accuracy, 62.76% explanation precision,
84.38% recall, 1.56% false-interaction rate, and 34.38% false-atomic-interest
rate. Action-type accuracy is 96.88%; top-1 relevance is 82.81%.

The main successes are explicit conjunctions, contradictory individual
artwork dislikes, and corrections. Each has 100% coverage, precision, recall,
action-type accuracy, and top-1 relevance except correction precision (87.5%)
and false-atomic rate (12.5%). The engine also abstains on all declared missing
evidence and ambiguous histories.

The failures are substantive:

- All four noisy profiles appear among returned mixed explanations but are not
  asserted as positive. Incidental atomic candidates make precision and top-1
  relevance zero for that family before clarification.
- `missing_portrait_hidden` loses the gold explanation entirely. The abstention
  is correct, but coverage is zero because the needed fact is unavailable.
- `ambiguous_albert` derives the conjunction although one of its two possible
  worlds has only an oil interest. Averaging those worlds yields the sole
  false-interaction contribution (0.5 for that scenario; 1.56% overall). It is
  never prioritized, and the system clarifies.
- `independent_nature_water` returns insufficient evidence instead of the
  authored recommendation action because no eligible candidate satisfies the
  deterministic primary choice. This is the sole action-type error.
- The flagship and `preference_interaction_016` have irrelevant raw top-ranked
  artworks before clarification. The corrected selected action is a
  clarification, so the ranking failure and action decision are reported
  separately.

These failures are preserved in
`evaluation/preference_state_corrected_results.json` and were not tuned away.

## Candidate-order invariance

Every scenario records its exact ordering and seed. A selected subset is run
under two further deterministic permutations. No offline method changed its
explanations, decision, or ranked output. Permutations have
`independent_sample_count: 0`; they are sensitivity checks rather than extra
benchmark cases. Direct-LLM order sensitivity will be reported from the same
audit when an API run is configured.

## Human review

`evaluation/preference_state_corrected_human_review.csv` contains 16 unscored
method-blind disagreements, including cases whose raw top-ranked artworks are
wrong in at least one controlled world. A/B positions are deterministically
randomized and the seed is recorded. Reviewers assess relevance,
overinterpretation, whether clarification is preferable, and usefulness as a
next step. The sheet contains text labels and ArtGraph attributes, not images;
it evaluates textual relevance rather than visual preference.

## Reproduction

```powershell
.\.venv\Scripts\python.exe scripts\build_preference_state_robustness.py
.\.venv\Scripts\python.exe -m evaluation.evaluate_preference_state_corrected
.\.venv\Scripts\python.exe scripts\build_preference_state_corrected_human_review.py
```

The machine-readable audit is `docs/preference_state_robustness_audit.json`.
The original Phase 0–1.2 hashes are frozen in
`docs/preference_state_historical_manifest.json`.
